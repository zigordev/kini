## Google OAuth setup

The API now issues sessions through Google OAuth 2.0 using Passport. To run it locally you need to:

1. Create an OAuth 2.0 Client in the [Google Cloud Console](https://console.cloud.google.com/apis/credentials). Use a "Web application" client type and add `http://localhost:3012/auth/google/callback` to the list of authorized redirect URIs. For mobile deep-links you can add additional redirect URIs later.
2. Copy the generated client id/secret into your `.env` file together with the new session variables:

```
GOOGLE_CLIENT_ID=your-google-client-id
GOOGLE_CALLBACK_URL=http://localhost:3012/auth/google/callback
AUTH_SUCCESS_REDIRECT_URL=http://localhost:8081/auth/callback
AUTH_FAILURE_REDIRECT_URL=http://localhost:8081/auth/callback
AUTH_CORS_ORIGINS=http://localhost:8081,http://localhost:19006
SESSION_COOKIE_NAME=kini.sid
SESSION_COOKIE_SECURE=false
SESSION_COOKIE_MAX_AGE_MS=604800000
```

3. Store `GOOGLE_CLIENT_SECRET`, `SESSION_SECRET`, and `SESSION_COOKIE_SECRET` in OpenBao for local compose. Use the read-only `kini-local-read` token described in `../../docs/local-first-start.md` as `OPENBAO_TOKEN`.
4. Install the new dependencies (Passport, Google strategy) and run the database with `DATABASE_SYNCHRONIZE=true` at least once so the new user columns are created.
5. Run the API and browse to `http://localhost:3012/auth/google` to confirm the OAuth flow works.

### New endpoints

- `GET /auth/google` – starts the Google OAuth flow. Accepts optional `redirect_uri` and `failure_redirect` query parameters so the mobile app can override where the API sends the browser afterwards.
- `GET /auth/google/callback` – receives Google's response and establishes a session (HTTP-only cookie).
- `GET /auth/google/config` – exposes public client metadata to the front-end.
- `GET /auth/me` – returns the authenticated user (requires a valid session).
- `POST /auth/logout` – destroys the active session.

Existing user records gained new fields (`email`, `googleId`, etc.), so make sure your database contains those columns if you already have data.

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```
